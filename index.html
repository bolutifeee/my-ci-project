CI/CD Pipeline with GitHub Actions

Personal QA & Automation Practice Project
Code → Pipeline runs → Live demo →

A fully automated CI/CD pipeline that runs on every push — linting code, testing across multiple Node versions, and deploying to GitHub Pages only when every quality gate passes. Built from scratch to understand what happens under the hood of modern QA automation.

  • Automated linting (ESLint) and unit tests (Jest) on every push
  • Matrix builds across Node.js 18, 20, 22, and 24 in parallel
  • Automated deployment to GitHub Pages after CI passes
  • Real failures caught by the pipeline — investigated and resolved
  • Full feedback loop: push → test → fail → fix → validate
  • Live status badge showing build health in real time
